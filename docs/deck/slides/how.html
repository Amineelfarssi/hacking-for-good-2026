What makes us different

Built for protocols, not for general chat

Reads like a clinician

It scans the outline, opens the right pages and reads them. No similarity guesswork, so the answer is the one the protocol gives.

Every fact has a page

Protocol, version, page and section on every statement. You verify in one click instead of trusting.

Honest about its limits

It asks when a question is unclear, refuses what is out of scope, and says so when a guideline is missing.

Outside evidence, clearly labelled

PubMed, FDA labels and web guidelines sit in a separate block. If they disagree with your protocol, it says so and the protocol prevails.

Built on Google Cloud (GCP). Cloud Run, Cloud Storage and Vertex AI, ready to deploy in a hospital setting.

The whole system runs on Google Cloud (GCP): Cloud Run for the web app and agent, Cloud Storage for the protocols, Vertex AI for the agent and evaluation. Four things set this apart from a general AI chatbot or a PDF search. It navigates the protocol like a clinician instead of guessing by similarity. Every fact carries its page. It is honest when it does not know. And outside evidence is labelled, never mixed in. Example for the fourth card: fever and neutropenia in induction. The protocol defers empiric antibiotics to local guidance; PubMed brings the 2023 paediatric guideline, ECIL-8 from the web, and the vincristine FDA label that contraindicates azoles. The assistant names the collision and says the protocol prevails.
