Meet the assistant that reads the protocol so the oncologist doesn't have to

Twenty-seven paediatric haemato-oncology trial protocols, 4,142 pages. A clinician on a shift asks one question and gets the answer with the exact page, highlighted. Here is how it thinks, in six pictures.

1 · It reads like a clinician

No vector index. It walks protocol, section, page.

The agent opens the protocol's table of contents (with a one-line summary per section), searches the text with synonyms, sees which sections had hits, and reads those pages. Nothing is embedded or guessed from similarity, so the page it cites is the page it read.

2 · Every fact carries its page

Click the chip, see the sentence.

Each statement ends with a chip: protocol, version, page, section. Clicking it renders that page with the quoted passage highlighted, found by exact match, then fuzzy match, then the neighbouring page when a citation spans two. Thresholds arrive as a small card, one citation per row.

3 · It asks before it guesses, and it says no

Two decisions before any search.

Out of paediatric haemato-oncology? It refuses in one sentence and runs no tool. Patient described but a deciding fact missing (AML or ALL, risk group, age, MYCN status)? It asks with a card of options and waits. Only then does it read.

4 · A second opinion, clearly labelled

External evidence orbits the protocol. It never merges.

When a complication, a co-medication or a gene matters, the assistant adds a separate block from PubMed, web guidelines, FDA labels, CPIC and ClinVar, each finding tagged with its source, and names the collisions. Example: an azole antifungal in a local SOP versus vincristine in ALLTogether1 induction. The protocol prevails; deviations go to the study team.

5 · Who does what

One reader, one quick helper.

Gemini 4 Argon: the reader

  • Decides scope, asks the clarifying question
  • Plans the sections, reads the pages, writes the cited answer
  • Judges when external evidence is needed and what collides
  • Same code locally, on Cloud Run and on Vertex AI Agent Engine

Gemini 3.8 Flash: the quick helper

  • Runs the web-search sub-agent for guidelines and regulators
  • Wrote the one-line summary of every protocol section, once
  • Grades answers against the oncologist's references in both evaluations
